# Customer-Behavior-Analysis
Customer Behavior Analysis is a data analytics project focused on understanding customer purchasing patterns, preferences, and business trends using real-world transactional data. The primary objective of this project is to extract meaningful insights from customer behavior data that can support better business decision-making. This project demonstrates an end-to-end data analysis workflow, including data cleaning, exploratory data analysis (EDA), feature engineering, SQL-based querying, and data visualization.

The analysis was performed using Python, along with libraries such as Pandas, NumPy, Matplotlib, and Seaborn for data manipulation and visualization. MySQL was used for storing the processed dataset and performing SQL queries for deeper analysis. Jupyter Notebook was used as the development environment for executing the analysis workflow.

The project began with data preprocessing, where missing values were handled, duplicate records were removed, and inconsistent data formats were corrected to ensure data quality. Additional features were engineered to make the dataset more useful for analysis, such as converting purchase frequency categories into numerical day values for easier computation and comparison.

Exploratory Data Analysis was conducted to understand customer demographics, product purchasing trends, discount usage patterns, subscription behavior, review ratings, shipping preferences, and spending behavior. Various business questions were explored, such as identifying the most frequently purchased products, measuring the impact of discounts on customer purchases, analyzing customer segments with higher spending behavior, and understanding how subscription status influences buying patterns.

SQL analysis was performed on the processed dataset to answer business-driven questions using aggregation, filtering, grouping, sorting, and conditional logic. Queries were written to calculate discount percentages, identify top-performing products, analyze average spending, and generate customer behavior insights from a database perspective.

Data visualization played a significant role in presenting insights clearly through charts and comparative visual analysis. These visualizations helped in identifying hidden trends and patterns that may not be immediately visible through raw data alone.

This project demonstrates practical data analyst skills including data cleaning, exploratory data analysis, SQL querying, feature engineering, business problem-solving, and data storytelling. It serves as a strong portfolio project for aspiring data analysts by showcasing the ability to work with real datasets, transform raw data into actionable insights, and communicate findings effectively.

Future enhancements for this project may include building an interactive dashboard using Power BI or Tableau, implementing predictive analytics models, and deploying the analysis as an interactive web-based reporting application.

Technologies Used: Python, Pandas, NumPy, Matplotlib, Seaborn, MySQL, SQLAlchemy, Jupyter Notebook.
